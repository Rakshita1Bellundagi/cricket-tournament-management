# Cricket Tournament Management System

Frontend-only React + Vite project.

## Run in Visual Studio Code

1. Install Node.js LTS.
2. Open this folder in Visual Studio Code.
3. Open Terminal.
4. Run:
   npm install
   npm run dev
5. Open the localhost URL shown by Vite.

## Pages

- Dashboard
- Tournaments
- Teams
- Players
- Matches
- Points Table

The project currently uses static frontend data. Forms and API/database integration can be added later.
